## Project Description
This program acts as an Analytical Chemistry Lab Assistant, designed to automate repetitive titration calculations for our group lab reports in Chem 12L.

The script demonstrates the core concepts of Python functions by utilizing:
* **Function Definitions (`def`):** Encapsulating the mathematical formulas for calculating moles and molarity into their own reusable blocks of code.
* **Parameters and Arguments:** Passing specific laboratory measurements (mass, molar mass, volume) into the functions securely.
* **Return Values:** Using the `return` statement to send calculated results back to the main program flow.
* **Function Integration:** Calling a function, storing its returned value in a variable, and passing that variable into a second function to complete a multi-step calculation.
